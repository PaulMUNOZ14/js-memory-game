# Jeu du Memory

### Pour jouer au jeu, [Cliquez ici](https://paulmunoz14.github.io/js-memory-game/).

## Description

Jeu de Memory réalisé en Vanilla JavaScript dans le cadre du BUT Informatique en 2ème Année

Le but du jeu est de retrouver les 8 paires de cartes identiques.

Les images sont générées grâce à l'API Picsum Photos.

## Technologies

- HTML5
- CSS3
- JavaScript ES6 (Vanilla JS)
- CSS Grid
- API Picsum Photos
- GitHub Pages

## Fonctionnalités

- Génération de 16 cartes
- Mélange des cartes avec l'algorithme Fisher-Yates
- Détection des paires
- Compteur de coups
- Chronomètre
- Détection de la victoire
- Réinitialisation du jeu
- Gestion des clics avec JavaScript
